🚀 AIFinder - Full-Stack AI Tool Discovery Platform

A full-stack web application designed to help users discover, filter, search, and bookmark AI tools for various workflows. Features real-time MySQL Full-Text Search ranking, dynamic pricing/category filters, responsive dark-mode glassmorphic UI, and persistent browser bookmarks.

![AIFinder Demo](frontend/public/demo.gif)

🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS v4, Lucide React Icons
- **Backend**: Java 17, Spring Boot 3, Spring Data JPA
- **Database**: MySQL 9.6 (InnoDB with Full-Text Search Indexing)
- **API Protocol**: RESTful JSON APIs with CORS Configuration
